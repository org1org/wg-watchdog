## Возможности

- отдельное задание для каждого интерфейса `WireguardN`;
- проверка внутреннего адреса WireGuard-сервера по расписанию;
- перезапуск только после заданного числа последовательных ошибок;
- защита от повторных перезапусков и пауза после загрузки роутера;
- безопасная работа с full-tunnel и необязательная проверка внешней доступности;
- полноэкранное меню `wgwm`, ручная проверка и принудительный перезапуск;
- просмотр последних событий из системного журнала KeeneticOS;
- транзакционное обновление с проверкой SHA-256 и автоматическим откатом;
- рабочее состояние хранится в `/tmp` без частых записей на накопитель Entware.

WG Watchdog Manager не изменяет ключи, пиры и конфигурацию WireGuard.

## Требования

- KeeneticOS 5 или новее;
- установленный Entware;
- SSH-доступ с правами `root`;
- настроенный клиентский WireGuard-интерфейс.

Установщик самостоятельно добавит пакеты `ndmq` и `cron`, если они отсутствуют.

## Установка

```sh
wget -qO- https://raw.githubusercontent.com/org1org/wg-watchdog/main/install.sh | sh
```

После установки запустите менеджер:

```sh
wgwm
```

Выберите WireGuard-интерфейс и пункт **Настроить watchdog**. Внутренний адрес
сервера и внешний Endpoint подставляются из конфигурации пира, когда их удаётся
определить автоматически.

## Использование

Для настроенного интерфейса доступны:

- проверка соединения сейчас;
- подробный статус;
- последние 20 событий системного журнала;
- включение и выключение задания;
- изменение параметров;
- подтверждаемый принудительный перезапуск;
- удаление задания watchdog.

Основные команды:

```sh
wgwm                 # полноэкранный менеджер
wgwm --plain         # обычный текстовый режим
wgwm --uninstall     # удаление программы
```

Обновление выполняется из главного меню `wgwm`.

## Настройки

Новые задания создаются со следующими значениями:

| Параметр | Значение |
|---|---:|
| Частота проверки | 5 минут |
| Ping-запросов | 3 |
| Ожидание ответа | 3 секунды |
| Ошибок до перезапуска | 2 |
| Пауза между `down` и `up` | 3 секунды |
| Проверка после перезапуска | через 15 секунд |
| Cooldown между перезапусками | 30 минут |
| Пауза после загрузки роутера | 180 секунд |

Все значения можно изменить отдельно для каждого интерфейса.

### Локальный порт WireGuard

Для исходящего клиентского туннеля поле **Порт прослушивания** рекомендуется
оставить пустым. Фиксированный локальный порт может помешать восстановлению
соединения после длительного обрыва.

Это не порт сервера в Endpoint. Адрес и порт удалённого сервера удалять нельзя.

## Удаление

```sh
wgwm --uninstall
```

Менеджер предложит удалить программу вместе с заданиями либо сохранить настройки
для последующей установки. Сторонние записи cron не изменяются.
