# WG Watchdog для KeeneticOS

Интерактивный установщик watchdog для WireGuard на роутерах Keenetic с установленным Entware.

Watchdog каждые пять минут проверяет доступность центрального WireGuard-сервера через туннель. Если обычный интернет работает, но сервер не отвечает на ping, выбранный WireGuard-интерфейс перезапускается штатными командами KeeneticOS через `ndmc`.

## Возможности

- показывает найденные WireGuard-интерфейсы Keenetic и их описания;
- предлагает выбрать нужный интерфейс;
- запрашивает внутренний IP-адрес WG-сервера и проверяет его доступность;
- при отсутствии ответа позволяет продолжить или отменить установку;
- настраивает число ping, тайм-аут и задержку перезапуска;
- устанавливает `cron`, добавляет задание без дублирования и включает автозапуск;
- не перезапускает WireGuard, если у роутера отсутствует обычный интернет;
- записывает перезапуски и ошибки в системный журнал.

## Требования

- KeeneticOS;
- установленный и запущенный Entware;
- SSH-доступ к Entware от пользователя `root`;
- WireGuard-интерфейс, настроенный средствами KeeneticOS;
- внутренний адрес WG-сервера должен отвечать на ping для корректного мониторинга.

## Установка одной командой

Подключитесь к Entware по SSH от `root` и выполните:

```sh
wget -qO- https://raw.githubusercontent.com/org1org/wg-watchdog/main/install.sh | sh
```

Установщик задаст необходимые вопросы на русском языке. Для числовых параметров достаточно нажать Enter, чтобы принять рекомендуемое значение.

## Значения по умолчанию

| Параметр | Значение | Назначение |
| --- | ---: | --- |
| `PING_COUNT` | `3` | Число ping-запросов при одной проверке |
| `PING_TIMEOUT` | `3` | Время ожидания каждого ответа, секунд |
| `RESTART_DELAY` | `3` | Пауза между выключением и включением интерфейса, секунд |

Проверка выполняется раз в пять минут.

## Установленные файлы

- `/opt/bin/wg-watchdog.sh` — watchdog;
- `/opt/etc/wg-watchdog.conf` — настройки;
- `/opt/etc/crontab` — добавляется задание запуска.

## Проверка работы

```sh
/opt/bin/wg-watchdog.sh
logread | grep wg-watchdog
grep wg-watchdog /opt/etc/crontab
```

## Изменение настроек

Настройки находятся в `/opt/etc/wg-watchdog.conf`. После изменения перезапуск cron не требуется: watchdog читает файл при каждом запуске.

## Удаление

Удалите строку watchdog из `/opt/etc/crontab`, затем выполните:

```sh
rm -f /opt/bin/wg-watchdog.sh /opt/etc/wg-watchdog.conf
/opt/etc/init.d/S10cron restart
```

Пакет `cron` не удаляется, поскольку он может использоваться другими программами Entware.

## Как работает восстановление

При потере связи watchdog проверяет наличие обычного интернета. Если интернет доступен, но WG-сервер не отвечает, выполняется штатный перезапуск выбранного интерфейса через `ndmc`.
